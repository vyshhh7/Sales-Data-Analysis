# Sales Data Analysis Dashboard

## 📊 Project Overview

This project focuses on analyzing sales data to understand business performance across different products, categories, regions, sales representatives, and customer segments.

The project uses **SQL** to answer key business questions and **Power BI** to create an interactive dashboard that presents the insights visually.

## 🎯 Problem Statement

A retail business needs a clear understanding of its sales performance to make informed decisions about products, regions, customers, and overall profitability. However, analyzing raw transaction data manually makes it difficult to identify important trends and high- or low-performing areas.

## 🛠️ Tools & Technologies Used

* **SQL** – Data querying and business analysis
* **MySQL**– Database management
* **Power BI** – Interactive dashboard and data visualization
* **DAX (Data Analysis Expressions)** – Creating calculated measures and key performance indicators (KPIs)

## 📂 Dataset

The dataset contains **1,000 sales records** with the following information:

* Product ID
* Sale Date
* Sales Representative
* Region
* Quantity Sold
* Product Category
* Unit Cost and Unit Price
* Customer Type
* Discount
* Payment Method
* Sales Channel
* Revenue and Cost

## 🔍 Business Questions Answered

The SQL analysis answers the following questions:

1. What is the total sales revenue?
2. What is the total profit?
3. What is the total quantity of products sold?
4. Which products generate the highest sales revenue?
5. Which products generate the highest profit?
6. Which categories have the highest sales and profit?
7. Which regions perform the best?
8. Which sales representatives generate the most revenue?
9. How do new and returning customers compare in sales?
10. What are the monthly sales trends?
11. Which products have the highest quantities sold?
12. What is the average order value?
13. Is a higher discount associated with higher sales?
14. Which products and categories have low sales or profit?


## 📊 Power BI Dashboard

An interactive Power BI dashboard was created to provide a clear overview of sales performance. The dashboard helps users explore key metrics and compare performance across different business dimensions using visualizations and filters.
